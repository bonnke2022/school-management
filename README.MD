# 📚 Library Management API

A RESTful API for managing a library system built with Node.js, Express, and MongoDB. It supports managing books, authors, students, and attendants, as well as borrowing and returning books.

---

## 🛠 Tech Stack

- **Node.js** — Runtime environment
- **Express.js** — Web framework
- **MongoDB** — Database
- **Mongoose** — ODM for MongoDB
- **http-status-codes** — HTTP status code constants
- **swagger-ui-express** & **swagger-jsdoc** — API documentation
- **express-async-errors** — Async error handling
- **dotenv** — Environment variable management

## 📦 Data Models

### Author

| Field     | Type       | Required | Notes                    |
| --------- | ---------- | -------- | ------------------------ |
| name      | String     | Yes      | Author's full name       |
| bio       | String     | No       | Short biography          |
| books     | [ObjectId] | No       | References to Book model |
| createdAt | Date       | Auto     | Generated by timestamps  |
| updatedAt | Date       | Auto     | Generated by timestamps  |

### Book

| Field      | Type       | Required | Notes                           |
| ---------- | ---------- | -------- | ------------------------------- |
| title      | String     | Yes      | Book title                      |
| isbn       | String     | Yes      | Unique identifier               |
| authors    | [ObjectId] | No       | References to Author model      |
| status     | String     | Auto     | "IN" or "OUT", defaults to "IN" |
| borrowedBy | ObjectId   | No       | Reference to Student model      |
| issuedBy   | ObjectId   | No       | Reference to Attendant model    |
| returnDate | Date       | No       | Set automatically on borrow     |
| createdAt  | Date       | Auto     | Generated by timestamps         |
| updatedAt  | Date       | Auto     | Generated by timestamps         |

### Student

| Field     | Type     | Required | Notes                         |
| --------- | -------- | -------- | ----------------------------- |
| name      | String   | Yes      | Student's full name           |
| email     | String   | Yes      | Unique email address          |
| studentId | ObjectId | Auto     | Set to \_id via pre-save hook |
| createdAt | Date     | Auto     | Generated by timestamps       |
| updatedAt | Date     | Auto     | Generated by timestamps       |

### Attendant

| Field     | Type     | Required | Notes                         |
| --------- | -------- | -------- | ----------------------------- |
| name      | String   | Yes      | Attendant's full name         |
| staffId   | ObjectId | Auto     | Set to \_id via pre-save hook |
| createdAt | Date     | Auto     | Generated by timestamps       |
| updatedAt | Date     | Auto     | Generated by timestamps       |

## 🔗 API Endpoints

Base URL: `/api/v1`

### Students

| Method | Endpoint        | Description          |
| ------ | --------------- | -------------------- |
| POST   | `/students`     | Create a new student |
| GET    | `/students`     | Get all students     |
| GET    | `/students/:id` | Get a single student |

#### POST `/students`

**Request Body:**

```json
{
  "name": "John Doe",
  "email": "johndoe@gmail.com"
}
```

**Response (201):**

```json
{
  "student": {
    "_id": "65f1a2b3c4d5e6f7a8b9c0d1",
    "name": "John Doe",
    "email": "johndoe@gmail.com",
    "studentId": "65f1a2b3c4d5e6f7a8b9c0d1"
  }
}
```

### Books

| Method | Endpoint            | Description                              |
| ------ | ------------------- | ---------------------------------------- |
| POST   | `/books`            | Create a new book                        |
| GET    | `/books`            | Get all books (with pagination & search) |
| GET    | `/books/:id`        | Get a single book                        |
| PATCH  | `/books/:id`        | Update a book                            |
| DELETE | `/books/:id`        | Delete a book                            |
| PATCH  | `/books/:id/borrow` | Borrow a book                            |
| PATCH  | `/books/:id/return` | Return a book                            |

#### POST `/books`

**Request Body:**

```json
{
  "title": "1984",
  "isbn": "978-0451524935",
  "authors": "65f1a2b3c4d5e6f7a8b9c0d3"
}
```

**Response (201):**

```json
{
  "book": {
    "_id": "65f1a2b3c4d5e6f7a8b9c0d4",
    "title": "1984",
    "isbn": "978-0451524935",
    "authors": ["65f1a2b3c4d5e6f7a8b9c0d3"],
    "status": "IN"
  }
}
```

#### GET `/books` — Query Parameters

| Parameter | Type   | Description                              | Example          |
| --------- | ------ | ---------------------------------------- | ---------------- |
| page      | Number | Page number (default: 1)                 | `?page=2`        |
| limit     | Number | Results per page (default: 10)           | `?limit=5`       |
| title     | String | Search by title (case-insensitive)       | `?title=1984`    |
| author    | String | Search by author name (case-insensitive) | `?author=George` |

**Response (200):**

```json
{
  "books": [...],
  "count": 5,
  "currentPage": 1,
  "totalPages": 3,
  "totalBooks": 25
}
```

#### PATCH `/books/:id/borrow`

**Request Body:**

```json
{
  "studentId": "65f1a2b3c4d5e6f7a8b9c0d1",
  "attendantId": "65f1a2b3c4d5e6f7a8b9c0d2"
}
```

**Response (200):**

```json
{
  "msg": "Book has been given out"
}
```

#### PATCH `/books/:id/return`

No request body needed.

**Response (200):**

```json
{
  "msg": "Book has been returned"
}
```

> When fetching a book with status "OUT", the response will include full student details, attendant details, and return date via `.populate()`.
